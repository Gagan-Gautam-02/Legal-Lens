💡 Project Overview

VeriLaw is a cutting-edge Generative AI platform designed to demystify complex legal documents and provide proactive legal guidance for individuals and new businesses in India. Powered by Google's Gemini AI, we eliminate inaccessible legal jargon and empower users to make informed decisions without constant, expensive legal counsel.

Problem Solved

The legal landscape is a major hurdle for new ventures and individuals.

Complexity and Risk: Legal documents are dense with jargon, making them impossible for the average person to understand and exposing them to hidden risks.

Foundational Challenges: New founders struggle to navigate the mandatory legal path (e.g., registration, IP, compliance) necessary for stable growth.

Language Barrier: Most legal resources are English-only, neglecting a massive, diverse user base.

🛠️ Technology Stack

VeriLaw is built on a modern, scalable, and secure architecture:

AI & Cloud Services (The Intelligence Layer)

Vertex AI - Gemini API: The core Large Language Model (LLM) for all intelligence features: summarization, jargon simplification, risk analysis, and multilingual chat.

Google Cloud Document AI: Used for robust and accurate text and clause extraction from various document formats (PDFs, images) before feeding the data to Gemini.

Google Cloud Platform (GCP): Provides the robust and secure infrastructure for hosting and running AI services.

Application (Frontend & Backend)

Frontend: Next.js with TypeScript for a fast, responsive, and type-safe user interface.

Backend: Next.js API Routes for secure handling of API calls, preventing exposure of API keys.

Database: Firebase (Firestore & Auth) for secure user authentication and real-time storage of chat history and document analysis results.
