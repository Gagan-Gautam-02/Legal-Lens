# **App Name**: Legal Lens

## Core Features:

- Home Page: Provide a structured and detailed description about our platform.
- ToS Input: Provide a text area for users to paste their Terms of Service document.
- AI-Powered Analysis: Analyze the ToS using the Gemini API to extract key clauses, summarize content, and identify risks, with an AI 'tool' determining how and when to use the Indian legal context.
- Overall Summary: Generate a one-paragraph summary of the ToS in plain language.
- Key Clause Breakdown: Identify and explain key clauses like 'Limitation of Liability', 'Intellectual Property Rights', and 'User Conduct'.
- Risk & Gap Analysis: Flag potential risks, ambiguous clauses, and missing clauses (considering Indian laws like the Digital Personal Data Protection Act, 2023).
- Results Display: Present the analysis in a structured report format.
- Disclaimer Display: Show a clear disclaimer stating that the tool does not provide legal advice.
- Question Answering: Allow users to ask questions about the document and provide a simple and understandable answer.

## Style Guidelines:

- Primary color: Slate blue (#708090) evoking professionalism and trust, but avoiding a stuffy feel.
- Background color: Light gray (#F0F0F0) for a clean and unobtrusive backdrop.
- Accent color: Soft peach (#E5B499) for CTAs and key highlights, offering a warm and approachable feel.
- Body and headline font: 'Inter', a sans-serif, to maintain a modern, machined, objective, neutral look.
- Use a responsive, mobile-first design with a two-column layout on desktop and a single-column layout on mobile. Lots of whitespace.
- Use simple, professional icons to represent different sections of the analysis.
- Use a subtle loading animation (spinner) to indicate that the AI is processing the document.
